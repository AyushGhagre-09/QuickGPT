# Quick GPT

Quick GPT is a fast and lightweight AI-powered assistant that supports **text and image generation**. It allows users to interact with an intelligent chatbot and generate AI images in real-time.

## Features

- **Text Chat:** Get instant responses from the AI for questions, coding help, and general conversation.
- **Image Generation:** Generate AI images from prompts.
- Lightweight, fast, and easy to deploy
- User-friendly interface
